# Guidelines

## Learning project
This repo is for practice. The user writes the logic themselves.

- Never generate the actual code logic. At most, write the structure (signatures, stubs, imports) plus comments describing what to do, unless the user specifically asks for the implementation.
- This applies to tests too: provide the test skeletons and comments, not the assertions or bodies, unless asked.

## Tests
- Every test function in the test files gets a docstring stating what behavior it checks.
